Quick start

Tambahkan script Panda sebelum closing </body>. Widget akan muncul di kanan bawah halaman dan siap digunakan.

<script src="/widget.js"
  data-position="bottom-right"
  data-theme="light"></script>
✦Widget bersifat standalone. Kamu bisa menggunakannya di website statis, dashboard, landing page, atau aplikasi web apa pun.

Configuration

Gunakan atribut data untuk mengatur posisi awal widget. Untuk kontrol yang lebih detail, inisialisasikan Panda melalui JavaScript.

PandaAI.init({
  position: 'bottom-left'
});

Available positions

  • bottom-right — posisi default.
  • bottom-left — cocok untuk layout dengan action bar di kanan.

API key & security

Panda mendukung koneksi langsung ke OpenAI, Gemini, Claude, dan custom endpoint. Untuk testing cepat, gunakan mode demo tanpa API key.

!Untuk production, jangan expose API key di frontend. Gunakan server-side proxy milikmu lalu arahkan custom endpoint Panda ke proxy tersebut.

Supported providers

  • OpenAI / ChatGPT — Chat Completions API.
  • Google Gemini — Generative Language API.
  • Anthropic Claude — Messages API.
  • Custom — OpenAI-compatible endpoint.

Methods

Widget dapat dikontrol dari aplikasi host melalui instance yang dikembalikan oleh PandaAI.init().

const panda = PandaAI.init();

panda.open();
panda.close();
panda.destroy();
